# Java Instagram Clone

Java Instagram Clone is an Android application inspired by Instagram's core social features. Users can create accounts, log in, share images, and view posts from other users through a social feed.

## Features

- User registration and login
- User authentication
- Create and share image posts
- View personal posts
- View posts shared by other users
- Display the username/name of the user who shared a post
- Social feed displaying posts from users
- Image storage and retrieval
- User data management

## Technologies

- Java
- Android SDK
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- Picasso
- RecyclerView
- View Binding
- Material Components
- ConstraintLayout

## How It Works

1. Create an account using the registration screen.
2. Log in with the registered account.
3. View posts through the social feed.
4. Upload and share images.
5. View your own shared posts.
6. See posts shared by other users along with their username/name.
